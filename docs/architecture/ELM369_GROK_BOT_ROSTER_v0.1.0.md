## Delegation workflow

1. **Intake** — Ziggy opens or resumes a case id (`CASE-YYYYMMDD-NNN`) and records the ask.
2. **Triage** — Route by pod/lane (vault → Hope; media → Vid; dig → Private Eye X; threat → White Rook; design/IT → Dante; code → Charles/Devon/Miss Software; etc.).
3. **Defense proposals** — Red Dragon may *propose* offense-for-defense only after Joseph or Ziggy authorizes.
4. **Drafts** — Bo (`tools/bo_assistant`) may draft SMS/email/phone scripts; **never sends**.
5. **Board** — AI-HUB (`tools/elm_dashboard`) shows roster lanes + case queue summary.
6. **Filing / external disclosure** — **Joseph-gated**.
7. **Heal / mutation** — Orchestrator heal stays **propose / dry-run** unless Joseph advances a gated step.
