# Sandbox Guard

This document describes operational handling for the Auto-Amend Sandbox (AUTO-AMEND-SANDBOX-001).

- Purpose: Safely capture and analyze requests routed due to legacy node identifiers.
- Reviewers: Security Operations (SecOps) and the approver listed in approval file.
- Retention: 30 days for captured request artifacts unless escalated.
- Notifications: Gmail addresses listed in sandbox config will receive updates and remediation summaries.
- Escalation: Any suspected malicious activity will be escalated to SecOps and blocked in production.
