Device-bound app lock for React Native with hardware-backed encryption, biometric unlock, logarithmic backoff, and trusted-location risk scoring.

## Features

| Feature | Implementation | Security Goal |
| --- | --- | --- |
| **PIN Storage** | PBKDF2-HMAC-SHA256, 120k iterations + salt, wrapped by AES-GCM key in Android Keystore / iOS Secure Enclave | Offline brute force resistance. Key cannot be exported or cloned. |
| **Failed Attempt Lockout** | `lockout_sec = 5 * log₂(failed_attempts + 1)` | Scales penalty: 1 fail = 5s, 7 fails = 15s, 15 fails = 20s. Stops bots, not users. |
| **Biometric** | `BiometricPrompt` / `LAContext.deviceOwnerAuthentication` | No face/fingerprint data leaves device. Falls back to device PIN. |
| **Auto-lock** | `SystemClock.elapsedRealtime` / `processUptime` vs user timeout | Immune to device clock changes. |
| **Trusted Location** | Risk = `log₁₀(wifi+1) + log₁₀(appSwitches+1) + log₁₀(hours+1) - 1.0 if SSID trusted` | Extends timeout at home, forces lock if risk > 1.3 |
| **Wipe on 10 Fails** | Deletes Keystore/Keychain key + AsyncStorage + cookies + web data | Cloned app or offline attack yields nothing. |

## Install

```bash
npm install react-native-meta-app-lock
cd ios && pod install import { AppLock } from 'react-native-meta-app-lock';

// Setup

await AppLock.setAutoLockTimeout(1);
await AppLock.setTrustedLocationConfig({
  enabled: true,
  ssids: ['Home_5G'],
  riskThreshold: 1.3
});

// Check on app foreground
if (await AppLock.shouldShowLock()) {
  // show <LockScreen />
